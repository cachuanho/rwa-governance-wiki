痛點拆解 ✦ Why Traditional Fails

為什麼讀了那麼多文章，
腦中還是像一盤散沙？

🌪️

資訊未內化，無法跟大腦簡報

看過的文章像過眼雲煙，因為沒有親自把概念「用自己的話講一遍」，真正要向別人報告或自己決策時，腦袋依然一片空白。

🔁

傳統 RAG：永遠在重新發現

NotebookLM 或一般 RAG 只是在問問題時抓片段。每一次提問都在重新檢索，知識永遠不會「跨文件沈澱與累積」。

🏚️

個人筆記難以長期維護

Notion 或 Obsidian 筆記本經常淪為文字墳場。人類受限於精力，難以在每次讀新文章時手動更新 10~15 個關聯頁面。

🧱

概念邊界模糊，缺乏對話辯析

單向閱讀無法檢視自己的理解漏洞。缺少一個隨時在線、能互相推敲法規與商業定義的「費曼對話者」。

核心心智模型 ✦ Mental Rehearsal

「跟我頭腦做簡報」的新工作法

把寫 Wiki 當成一場大腦的預演。如果你能跟 Agent 講清楚，你就真正掌握了它。

📖

1. 閱讀原文

吸收原始生硬資訊，標記出最難懂、最容易混淆的法規條文與財務數據。

🗣️

2. 跟 Agent 解釋概念

費曼學習法實踐：用自己的白話向 Agent 講一遍，由 Agent 追問盲點並補充交叉引用。

🧠

3. 大腦簡報成型

在腦中形成清晰邏輯線，確認自己真的懂了，再由 Agent 一鍵沉澱為結構化 Wiki 頁面！

💬 點擊上方「💬 概念討論與人機對話」分頁，即可查看我們在星宇航空估值與 RWA 專法中的真實辯析紀錄！
系統架構 ✦ Three-Tier System

LLM Wiki 的三層運作結構

🔒

1. 原始來源 (Raw Sources)

真相的基石（唯讀）

存放 PDF、PPTX、報告與法規。LLM 永遠只讀不改，保留不可篡改的客觀事實與歷史版本依據。

🧠

2. 知識庫 (The Wiki)

大腦的持久化延伸

由 LLM 完全維護的 Markdown 資料庫。包含 Source 摘要、Concept 核心概念、Entity 實體，以及全域 index.md 與時序 log.md。

📋

3. 操作規範 (AGENTS.md)

Agent 的靈魂與行為法則

定義如何討論、何時更新索引、Frontmatter 格式與 GitHub Pages 輸出準則，使 LLM 成為高度自律的知識夥伴。

深度比較 ✦ Paradigm Shift

傳統 RAG vs LLM Wiki

比較面向 傳統 RAG LLM Wiki 模式（大腦共創）
知識型態 資料庫中的被動向量碎片（Chunks） 結構化、互相鏈接的 Markdown 知識網
學習機制 問答時臨時拼湊，對話結束即遺忘 經人機討論後持續複利累積
與大腦的關係 搜尋引擎替代品，缺乏心智理解 先向頭腦做簡報，實現真正內化
跨文件矛盾 被動輸出可能相衝突的段落 主動在 Concept 頁標註不同來源的爭端
流程設計 ✦ Loop & Graph

三大關鍵迴圈（Loop）的運作

📥

Ingest 討論迴圈

1. 讀入新文件
2. 人機對話釐清概念
3. 建立 Source 頁面
4. 跨頁擴充 Concept / Entity
5. 自動更新 Index 與 Log

🔍

Query 輸出迴圈

1. 查閱 index.md 目錄
2. 聚合多份概念與引用
3. 合成教學型簡報結構
4. 優秀成果再回寫 Wiki

🔧

Lint 維護迴圈

1. 掃描孤兒頁面（無連結）
2. 檢測新舊法規矛盾
3. 揪出未定義的重要實體
4. 保持知識網強韌健康

✈️ 討論場景一：星宇航空 IPO 估值模型矛盾辯析（DCF vs DDM）
我
我讀了 Starlux.docx 報告，我想先向我的頭腦做簡報：
報告用了兩種方法估價，DCF 算出來是 NT$30.53，但 DDM 股利折現只有 NT$20.69。為什麼這兩種估值會差快 10 塊錢？我應該怎麼向別人解釋這個差距？
AI
很敏銳的問題！這正是理解這份財報的關鍵樞紐。讓我們這樣向大腦解釋：
1. 星宇處於「機隊高資本支出擴張期」：2024~2028 年大買飛機（從 24 架衝到 70 架），累計虧損 75 億要先彌補，因此 2024~2029 前五年完全「不發股利」！
2. DDM（股利折現）算的是「保底價值」：因為它是從 2030 年才開始算配息（股利率 30%~60%），折現回來只有 NT$20.69，這代表「只看現金回饋的保守防守底線」。
3. DCF（自由現金流）算的是「成長潛力」：它把機隊擴張 70 架後的整體企業營運現金流全部算進去，得出 NT$30.53，代表「星宇成熟後的真實內在價值」。
👉 結論口訣：DDM 是防守底線（20 元），DCF 是成長目標（30~35 元）！
我
我懂了！這就解釋了為什麼報告建議的目標價區間是 NT$20~35 元。那我們可以把這個邏輯存進 Wiki 的 DCF 概念頁嗎？
✅ 討論成果已自動沉澱至 Wiki：更新 wiki/concepts/DCF貼現現金流.md，建立 wiki/entities/星宇航空.md！
🏛️ 討論場景二：RWA 在台灣《虛擬資產服務法》中的定位與灰色地帶
我
我想確認 RWA 在台灣法規的地位：
台灣 2024 年通過了《虛擬資產服務法》，那如果有人把房地產或公司債代幣化（RWA），它是直接適用這部專法嗎？
AI
這裡有一個極常被誤解的法律邊界！
台灣採的是「實質判斷原則」，不能只看它叫代幣就歸專法管：
• 如果它具備「有價證券」性質（有投資契約、分享利潤）：它會落入《證券交易法》的 STO（證券型代幣） 規範，受金管會證期局監管，門檻極高。
• 如果它屬效用型代幣或其他虛擬資產：才由《虛擬資產服務法》的 VASP 許可制 規範（需要資本額 1 億、洗錢防制、資產隔離）。
👉 大腦一句話總結：RWA 資產上鏈「實質重於形式」，帶收益特性的要走 STO，純服務平台才走 VASP 專法！
✅ 討論成果已自動沉澱至 Wiki：更新 wiki/concepts/RWA代幣化.md 與 wiki/concepts/VASP許可制.md！

• 檢查前移：把檢查大幅「左移」到寫入 Wiki 前的【人機對齊對話】，大腦過關才准存入 Wiki。
